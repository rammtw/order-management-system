## Система управления заказами (Order Management System)


> Микросервисная платформа для обработки заказов интернет-магазина, где каждый компонент стека играет естественную роль.

```
Client (gRPC)
    │
    ▼
┌──────────────┐    Kafka    ┌──────────────────────┐
│ Order Service│ ──────────► │ Notification Service │
│   (Go + PG)  │             └──────────────────────┘
│              │    Kafka    ┌───────────────────┐
│              │ ──────────► │ Inventory Service │
│              │             │    (Go + PG)      │
└──────────────┘             └───────────────────┘
```
